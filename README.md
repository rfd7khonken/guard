# 🌲 ระบบจัดการตารางเวรยาม ศูนย์ป่าไม้ขอนแก่น (กลางวัน / กลางคืน)

ระบบบริหารจัดการและจัดตารางเวรยามแบบ Single-Page Application (SPA) พัฒนาด้วย Bootstrap 5, FontAwesome, Chart.js และ SweetAlert2 ออกแบบมาสำหรับ **ศูนย์ป่าไม้ขอนแก่น** รองรับการจัดเวร 2 กะ พร้อมระบบเข้าสู่ระบบ (RBAC), บันทึกประวัติการใช้งาน (Activity Logs), และการแจ้งเตือนผ่าน LINE Messaging API

---

## ✨ ฟีเจอร์หลักของระบบ

1. **ระบบปฏิทินแสดงผล 2 กะในช่องเดียว:**
   * ☀️ **เวรกลางวัน (08.30 - 16.30 น.):** ปฏิบัติหน้าที่เฉพาะวันหยุดราชการ (เสาร์-อาทิตย์ และวันหยุดนักขัตฤกษ์) พร้อมแสดงสถานะ `วันทำการปกติ` ในวันธรรมดา
   * 🌙 **เวรกลางคืน (16.30 - 08.30 น.):** ปฏิบัติหน้าที่ทุกวัน หมุนเวียนบุคลากร 7 คน พร้อมอัลกอริทึม **ป้องกันการซ้ำวันในสัปดาห์ (Sliding Window 6 วันล่าสุด)** และคำนวณต่อเนื่องข้ามเดือนอัตโนมัติ

2. **เริ่มต้นอ้างอิงจากพฤศจิกายน พ.ศ. 2569:**
   * ตั้งค่าเริ่มต้นฐานข้อมูลให้ตรงกับหนังสือคำสั่งศูนย์ป่าไม้ขอนแก่น ที่ ๑๐/๒๕๖๙ (ลงวันที่ 30 ตุลาคม พ.ศ. 2569) 100%
   * เมื่อกดปุ่ม *"คำนวณจัดเวรเดือนนี้อัตโนมัติ (นับต่อจากเดือนเดิม)"* ระบบจะดึงคิวสุดท้ายจากเดือนก่อนหน้ามานับหมุนเวียนต่อทันที

3. **ระบบป๊อปอัป (Pop-up Modal) รายละเอียดรายวัน:**
   * คลิกที่วันใดก็ได้ในปฏิทินเพื่อดูรายชื่อและเบอร์โทรศัพท์ติดต่อ
   * รองรับ **Manual Override** (สลับเปลี่ยนตัวผู้เข้าเวรเฉพาะวัน) และกำหนดวันหยุดราชการพิเศษได้ทันที

4. **แบบฟอร์มคำสั่งราชการ (รองรับพิมพ์ / PDF):**
   * แสดงบัญชีรายชื่อผู้อยู่เวรยามแยกชุดกลางวันและกลางคืน แปลงตัวเลขเป็น **เลขไทย** ตามรูปแบบหนังสือราชการ สามารถสั่งพิมพ์หรือบันทึกเป็น PDF ได้ทันที

5. **Dashboard & สถิติความเท่าเทียม (Fairness):**
   * กราฟและตารางสรุปสถิติจำนวนวันเข้าเวรของบุคลากรแต่ละคนเพื่อตรวจสอบความโปร่งใส

6. **ระบบเข้าสู่ระบบและสิทธิ์การใช้งาน (RBAC):**
   * **Admin:** แก้ไขตารางเวร จัดการสมาชิก วันหยุด ตั้งค่า API และดูประวัติการใช้งาน (Logs)
   * **Viewer:** ดูตารางเวร Dashboard และพิมพ์แบบฟอร์มคำสั่งราชการ

7. **ระบบประวัติการใช้งาน (Activity Logs) & ส่งออก CSV:**
   * บันทึกทุกความเคลื่อนไหว (Login, แก้ไขเวร, เปลี่ยนแปลงรายชื่อ, ส่ง LINE) พร้อมช่องค้นหา กรองประเภท และส่งออกเป็นไฟล์ CSV

8. **เชื่อมต่อ Google Sheets & LINE Messaging API:**
   * สำรองข้อมูลและซิงค์ข้อมูลผ่าน Google Apps Script (GAS) พร้อมระบบแจ้งเตือนตารางเวรเข้า LINE Group / ส่วนตัว

## 🚀 ขั้นตอนการนำขึ้น GitHub Pages (ใช้งานออนไลน์ฟรี)

1. สร้าง Repository ใหม่บน [GitHub](https://github.com) (เช่น `duty-roster-khonkaen`) กำหนดเป็น **Public**
2. อัปโหลดไฟล์ `index.html` ลงใน Repository
3. ไปที่แท็บ **Settings > Pages**
4. ที่หัวข้อ **Build and deployment > Branch** ให้เลือกเป็น `main` (โฟลเดอร์ `/ (root)`) แล้วกด **Save**
5. รอ 1-2 นาที จะได้ลิงก์เว็บไซต์สำหรับเปิดใช้งานผ่านมือถือและคอมพิวเตอร์

---

## 🔌 การตั้งค่า Google Apps Script และ LINE API (หลังบ้าน)

1. สร้างไฟล์ **Google Sheets** ใหม่ ตั้งชื่อว่า `DutyRoster_DB`
2. ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. วางโค้ด Google Apps Script สำหรับรับส่งข้อมูล State และส่งข้อความ LINE
4. กด **Deploy > New Deployment > Web App** ตั้งค่าดังนี้:
   * **Execute as:** `ฉัน (Me)`
   * **Who has access:** `ทุกคน (Anyone)`
5. คัดลอก **Web App URL** มาวางในช่องตั้งค่าบนหน้าเว็บไซต์
